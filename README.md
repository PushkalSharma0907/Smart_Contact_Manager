Smart Contact Manager is a full-stack Spring Boot web application designed to help users securely manage their personal contacts.
It provides features such as user authentication, OTP-based password reset, contact creation and editing, email integration, and a responsive user interface built with Thymeleaf. 
The backend is powered by Spring Boot and Spring Security, with a clear separation of concerns across packages for configuration, controllers, repositories, entities, helpers, and services. 
The frontend is organized into Thymeleaf templates, including user dashboard pages, profile management, settings, and contact details, while static assets like CSS and JavaScript are stored separately.
The application uses MySQL as its database through Spring Data JPA and integrates JavaMailSender for email functionality.
Overall, this project demonstrates a secure, scalable, and recruiter-ready architecture that highlights practical real-world use cases and modern development practices.
